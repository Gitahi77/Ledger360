## Universal Definition of Done
Every work order and PR must meet the following checklist:
- [ ] Code merged
- [ ] Tests added
- [ ] Documentation updated
- [ ] ADR updated (if architecture changed, in `../adr/`)
- [ ] Technical debt register updated
- [ ] Benchmarks executed (if performance changed, added to `../performance/benchmark-history/`)
- [ ] Observability added
- [ ] Rollback documented
- [ ] Security reviewed
